# Contributor Covenant Code of Conduct

Our community is dedicated to providing a harassment-free experience for everyone. All participants are expected to behave respectfully.

Be kind and respectful in all interactions. Harassment, hate speech, or abusive language will not be tolerated.

If you witness or experience unacceptable behavior, please contact the project maintainers.

This project follows the Contributor Covenant: https://www.contributor-covenant.org/
